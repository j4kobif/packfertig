# Packfertig 🧳

Packlisten für Urlaub, Sport und jeden anderen Anlass – direkt im Browser, auch am Handy.

## Funktionen

- **Urlaub / Koffer:** Anzahl der Tage wählen, optional mit Ersatz-Klamotten (z. B. 7 Unterhosen für 5 Tage), Wetter am Ziel und Aktivitäten (Strand, Wandern, Flug …). Die Mengen werden automatisch berechnet und lassen sich später über „Tage & Reserve“ anpassen.
- **Sporttasche:** Sportart (Fußball, Fitnessstudio, Laufen, Schwimmen, Allgemein) und Anlass (Training oder Spiel / Wettkampf).
- **Eigene Listen:** leer starten und eigene Kategorien anlegen.
- **Teilweise abhaken:** Bei Sachen mit Menge auf das Mengen-Feld tippen, z. B. 5 von 7 Socken eingepackt → „5/7“. Erst wenn alles drin ist, wandert es nach „Eingepackt“.
- **Reiseoutfit:** festlegen, was du am Reisetag anziehst. Pro Teil wählbar: *zählt als eingepackt* (z. B. 2 Pullis geplant, 1 angezogen → 2/2 sobald einer im Koffer ist) oder *zusätzlich* (Socken & Unterhose – die geplante Menge bleibt). Dazu Sachen, die nur angezogen werden (z. B. Jeans).
- **Abhaken:** Eingepacktes verschwindet nicht, sondern landet in jeder Kategorie unter „✓ Eingepackt“. Antippen packt es wieder aus.
- **Speichern:** Alles wird automatisch im Browser gespeichert. Über „Backup herunterladen / laden“ kannst du deine Listen auf ein anderes Gerät mitnehmen.
- **Offline & Home-Bildschirm:** Einmal öffnen, dann klappt's auch im Flugmodus. In Safari über Teilen → „Zum Home-Bildschirm“ wie eine App nutzen.
- Listen duplizieren, umbenennen, alles auspacken, löschen (mit Rückgängig).
- Schnell hinzufügen mit Menge: `3x Badetuch` oder `Badetuch x3`.

## Technik

Reines HTML, CSS und JavaScript – kein Build-Schritt. Läuft auf GitHub Pages.
